Sistema de Rotas para Entregas

===============================



A empres ACME-LTDA deseja determinar o caminho mais curto entre centros de distribuição 

localizados em diferentes cidades.

As cidades serão representadas por um grafo ponderado.

Cada vértice representa uma cidade.

Cada aresta representa uma estrada com uma distância em quilômetros.



--- O sistema deve receber:

  cidades, estradas, cidade de origem, cidade de destino



e informar:

  - menor distância

  - caminho percorrido



--- Requisitos Obrigatórios

Parte 1 - Estrutura do Grafo

  Implementar uma classe Grafo utilizando lista de adjacência



  Exemplo:

      {

      "cidadeA": [("cidadeB", 4), ("cidadeC", 2)],

      "cidadeB": [("cidadeD", 5)],

      "cidadeC": [("cidadeD", 8)]

      }



Parte 2 - Algoritmo

  Implementar o algoritmo de Dijkstra.



  O algoritmo deve retornar:

    - distancia_total

    - caminho

 

  Exemplo:

    Distância Percorrida: 12 km

     

    Caminho:

      Porto Alegre

      - Canoas

      - Novo Hamburgo

      - São Leopoldo
